A deterministic program that writes a one-line apology from an office printer (at most 120 characters) to `/output/entry.txt`. It holds three hand-written candidate apologies, scores each 0–5 against the judge's five criteria (a genuine apology with the printer's own gripes, the laugh, printer truth, freshness, economy of words), and picks the highest-scoring one. Fully deterministic: no randomness, no clock, no network, no file reads.

## Run it

```sh
python3 main.py
```
